📌 Frequently Asked Questions
Everything you need to know about FileMagic Pro
🔐 Are my files safe? ▼
Yes! All file processing happens locally in your browser. No file is ever uploaded to any server. Files are never stored, and after you close the tab, everything is gone. 100% private and secure.
📏 Is there a file size limit? ▼
Maximum file size is 300MB per file. For PDF merging, total combined size should not exceed 300MB. This ensures smooth performance in your browser.
🆓 Is FileMagic Pro really free? ▼
Absolutely free. No hidden charges, no premium tiers. All tools are completely free to use, with no watermarks or limitations.
🌐 Do I need an internet connection? ▼
An internet connection is required to load the page and libraries. However, once loaded, all processing works offline (thanks to PWA). You can use most tools without internet.
