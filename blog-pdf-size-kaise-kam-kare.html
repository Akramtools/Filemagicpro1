PDF ka size zyada kyun ho jata hai?

Zyadatar time, PDF me high-resolution scanned images ya photos hoti hain jo file ko heavy bana deti hain. Text-only PDF chhoti hoti hai, lekin scanned documents (jaise Aadhaar, marksheet, ya photo wale forms) aksar 2-5 MB tak ho jaate hain — jabki email/WhatsApp par 1 MB se kam wali file chahiye hoti hai.

Achhi quality bhi banaye rakhne ka tarika

Agar aapki PDF me important photos hain (jaise ID card scan), to zyada compression na karein — halka compression bhi file size kaafi kam kar deta hai bina text ya photo blurry kiye. Zyadatar cases me 60-70% size reduce ho jata hai bina kisi noticeable quality loss ke.
