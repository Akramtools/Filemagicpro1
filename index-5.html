Frequently Asked Questions
🔐 Are my files safe and private?▼
Yes. All processing (PDF, image, compression) happens entirely in your browser using JavaScript. No file is ever sent to any server. Background Remover uses a secure proxy, but your file is not stored.
📏 What is the maximum file size?▼
Maximum file size is 300MB per file. For very large files, processing may take longer depending on your device speed.
🆓 Is it really free forever?▼
Yes! All 24+ tools are completely free with no hidden charges, no premium plans, and no watermarks added to your files.
📱 Which browsers are supported?▼
Chrome, Firefox, Safari, Edge, Samsung Browser and all modern browsers on Android, iOS, Windows and Mac.
📋 What file formats are supported?▼
PDF, JPG, PNG, WEBP, DOCX, TXT, XLSX, XLS, CSV and more. Each tool page lists its supported formats.
🔗 Can I merge more than 2 PDFs?▼
Yes! You can select multiple PDF files at once in the Merge PDF tool. Select all files together in your file browser and they will all be merged in order.
